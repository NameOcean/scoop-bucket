# NameOcean Scoop bucket

```powershell
scoop bucket add nameocean https://github.com/NameOcean/scoop-bucket
scoop install nameocean
```

The manifest in `bucket/` is written by the NameOcean CLI release. Documentation:
https://nameocean.net/developers/cli/ · Issues: https://github.com/NameOcean/nameocean-cli-releases/issues
